## [v0.4.0] - 2026-07-11

### Highlights

- Agent-optimized output format is now the default for CLI and MCP tools
- Design system integration for token-aware remediation suggestions
- Source code mapping via source maps for locating issues in source files
- Validation delta for autonomous fix loop (audit → fix → validate → repeat)

### Added

- Agent-optimized JSON output as default format (use `--human` for human-readable output)
- `--design-system` CLI flag to specify design system spec for token suggestions
- `--source-map` CLI flag to specify source map directory for source code mapping
- `types/fix_pattern.go`: Agent output types (`AgentFinding`, `AgentResult`, `AgentRemediation`, `AgentSummary`)
- `types/fix_pattern.go`: Fix pattern types (`FixPattern`, `FixAction`, `FixType`)
- `types/fix_pattern.go`: Design system integration types (`TokenSuggestion`, `ElementContext`, `DesignSystemInfo`)
- `types/fix_pattern.go`: Source location types (`SourceLocation`, `Framework`)
- `types/delta.go`: Validation delta types (`ValidationDelta`, `FixedFinding`, `DeltaStatus`)
- `sourcemap/`: Source map parsing and element-to-source mapping
- `delta/`: Before/after comparison with fingerprinting and regression detection
- `config/fixes.go`: Project-specific fix configuration from `~/.plexusone/a11y/fixes.yaml`
- `config/project.go`: Auto-detection of language, framework, and component library
- `config/resolve.go`: Multi-level fix pattern resolution (project > library > language > builtin)
- `remediation/patterns.go`: Fix pattern registry mapping WCAG techniques and axe rules to actionable fixes
- `remediation/designsystem.go`: Design system loader with color token suggestions for contrast fixes
- `remediation/transform.go`: Transformer to convert standard findings to agent-optimized format
- `AgentOptimized()` and `AgentOptimizedJSON()` methods on `Result` type
- MCP tools now return agent-optimized JSON with fix patterns
- CLI `validate` command for comparing audits against baseline
- CLI `config show` command to display resolved project configuration
- CLI `config init` command to create default fixes.yaml
- Finding fingerprint (`Fingerprint()` method) for stable issue identification across audits

### Changed

- Default CLI output format changed from human-readable to agent-optimized JSON
- MCP `audit_page` and `audit_site` tools return structured agent JSON instead of text

### Documentation

- Agent Output section in report formats guide with JSON structure documentation
- MCP reference updated with agent-optimized output examples
- README updated with `--human` and `--design-system` flag examples
- Roadmap updated with validation delta implementation status
