## [v0.5.0] - 2026-09-20

### Highlights

- Honest conformance: criteria that were not assessed are reported as "Not Evaluated" (never assumed "Supports"), with the evaluation method recorded per criterion
- Proactive criterion evaluation in two interchangeable modes — local (agent, no API key) or API — sharing one prompt and verdict schema, to judge criteria automation can't resolve
- New specialized checks: resize (1.4.10), hover (1.4.13), and flashing content (2.3.1)
- Page evidence (screenshot, rendered HTML, structure) captured during audits and per journey state
- Conformance, OpenACR, and proactive evaluation now exposed as `Result` methods

### Added

- Proactive criterion evaluation (`llm/criteval.go`): an `APIEvaluator` (omnillm) and a local bundle flow (`BuildBundle` -> agent judge -> `ParseVerdicts`) sharing one prompt and verdict schema ([`d4d8ea4`](https://github.com/plexusone/agent-a11y/commit/d4d8ea4))
- Honest per-criterion conformance (`report.EvaluateConformance`): criteria with no finding and a judgment method are "Not Evaluated"; `report.ApplyVerdicts` resolves them only from real verdicts and never overrides a finding-backed result ([`6258047`](https://github.com/plexusone/agent-a11y/commit/6258047))
- `Result` methods exposing conformance, OpenACR, and proactive evaluation: `Conformance`, `OpenACR`, `EvaluationBundle`, `EvaluateCriteria`, `ConformanceWithVerdicts` ([`24a38cd`](https://github.com/plexusone/agent-a11y/commit/24a38cd))
- Specialized runner now executes resize, hover, and flashing-content checks ([`d5a7eca`](https://github.com/plexusone/agent-a11y/commit/d5a7eca))
- Page evidence (screenshot, rendered HTML, structure) captured during audits via `pagecapture` and stored on `PageResult.Evidence` ([`aade992`](https://github.com/plexusone/agent-a11y/commit/aade992))
- Page evidence captured per journey state (`StepExecutionResult.Evidence`) ([`a06bbb6`](https://github.com/plexusone/agent-a11y/commit/a06bbb6))

### Fixed

- Corrected WCAG criterion evaluation-method classifications so only criteria the specialized runner executes are `MethodSpecialized`, and `MethodAutomated` requires real axe rules (guarded by `wcag/method_coverage_test.go`) ([`78362bb`](https://github.com/plexusone/agent-a11y/commit/78362bb))

### Dependencies

- _1 dependency update_

### Documentation

- Proactive Criterion Evaluation guide (`docs/criterion-evaluation.md`) and the load-bearing honesty model documented; added repo `CLAUDE.md` ([`392d1c8`](https://github.com/plexusone/agent-a11y/commit/392d1c8))
